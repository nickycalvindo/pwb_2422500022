# PWB 2422500022

Aplikasi Toko Online Sederhana menggunakan CodeIgniter 3 untuk memenuhi tugas mata kuliah Pemrograman Web Bisnis.

## Fitur

- Menampilkan produk.
- Registrasi pelanggan.
- Login dan logout pelanggan.
- Profil pelanggan.
- Halaman administrator.

## Teknologi

- PHP
- CodeIgniter 3
- MySQL/MariaDB
- Bootstrap
- HTML, CSS, JavaScript

## Cara Menjalankan

1. Letakkan proyek dalam folder `htdocs`.
2. Jalankan Apache dan MySQL melalui XAMPP.
3. Buat database `pwb_2422500022`.
4. Import `database/pwb_2422500022.sql`.
5. Pastikan konfigurasi database dan `base_url` sesuai.
6. Buka `http://localhost/pwb_2422500022/`.
